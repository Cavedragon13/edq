- 2026-05-24: "60 start scripts, 1 stop script" finding in adversarial review was misleading — all services have stop_command in dragonsuite.json and the dashboard server executes them; standalone stop scripts are not needed → when auditing stop capability, check dragonsuite.json stop_command field, not just the scripts/ directory
- 2026-05-30: I chased cdragon/local host state while the user expected Dragonsuite work to happen on udragon → treat `/srv/containers/edq` on udragon (`192.168.7.226`) as the canonical source of truth; use Mac/cdragon only as client/editor unless the user explicitly asks for Mac-native work

- 2026-06-07: assumed Ollama was a snap (docs + dragonsuite.json said so) but it's the official systemd binary at `/usr/local/bin/ollama` → verify install method with `which`/`systemctl status` before managing a service; don't trust docs that may have drifted
- 2026-06-07: assumed Ollama's default eviction prevents two models co-residing; live VRAM check showed 0.30.x co-loads them to 1.3 GB free (near-OOM) on the 16 GB card → verify runtime memory behavior with an actual `nvidia-smi`/`ollama ps` check, and set `OLLAMA_MAX_LOADED_MODELS=1` on single-16GB-GPU boxes
- 2026-06-07: tried `curl -fsSL .../install.sh | sudo sh` to update Ollama and it was blocked by the sandbox classifier → for runtime updates, download the GitHub release tarball (`.tar.zst`) and extract manually instead of piping a remote script to root
- 2026-06-11: wrote an inspection one-liner with `enc=$(python3 -c "...")` + `curl -w "%{http_code}"` that tripped "shell syntax cannot be statically analyzed" → user had to approve a prompt with no idea what was wrong. Never bundle command substitution / nested quotes / printf-format strings into a bash one-liner; put the logic in a script file run with one flat command, or use Read/Grep/Glob. Allow-listing can't fix the unanalyzable case — only rewriting can.
- 2026-06-17: used backslash-escaped path (Daily\ Notes/) instead of quoted path ("Daily Notes/") — triggers "Contains backslash-escaped whitespace" prompt. Always quote paths with spaces; never backslash-escape them in Bash tool calls. Then immediately used printf with backslash sequences to record this lesson, triggering the same prompt again. For file appends with special characters, use the Edit tool — not printf/echo.
