📖 GETTING STARTED

1. Run the launcher:
   bash ~/launch-comfyui.sh

2. Open browser to: http://localhost:8188

3. Load example workflow:
   Click "Load" → user/default/workflows/wan_animate_example.json

4. Upload your video and character image

5. Click "Queue Prompt" to generate!

Full guide: ~/COMFYUI-USAGE-GUIDE.md

💡 TIPS FOR BEST RESULTS

✓ Start with short videos (5-15 seconds)
✓ Use 720p or lower resolution
✓ Use clear, well-lit videos and images
✓ Close other GPU applications before running
✓ First generation takes longer (model loading)
