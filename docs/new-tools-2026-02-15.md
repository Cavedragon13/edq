## Tool Details

### 1. JustDubit (Port 8022)

**Category:** Audio/Video Processing
**Status:** ⚠️ Requires model downloads
**Project:** `/srv/containers/edq/projects/just-dub-it`
**Venv:** `.venv` (uv-managed)

**What it does:**

- Multilingual video dubbing
- Synchronized lip-sync using audio-visual diffusion
- Preserves speaker identity
- Uses LTX-2 19B base model

**Required models (~50GB):**

1. LTX-2 AV Checkpoint (ltx-2-19b-dev.safetensors)
2. JustDubit LoRA (ltx-2-19b-ic-lora-lipdubbing.safetensors)
3. Distilled LoRA (ltx-2-19b-distilled-lora-384.safetensors)
4. Spatial Upscaler (ltx-2-spatial-upscaler-x2-1.0.safetensors)
5. Gemma Text Encoder (gemma-3-12b-it-qat-q4_0-unquantized)

**Download from:** https://huggingface.co/justdubit/justdubit

**Launch:** `bash scripts/start_justdubit.sh`

**Next steps:**

- Download model checkpoints
- Update checkpoint paths in `scripts/justdubit_gradio.py`
- Test with sample video

### 2. SoulX-Singer (Port 8023)

**Category:** Audio/Music
**Status:** ✅ Ready to use
**Project:** `/srv/containers/edq/projects/SoulX-Singer`
**Venv:** `/srv/containers/edq/venv_soulxsinger`

**What it does:**

- Zero-shot singing voice synthesis
- Voice cloning for singing
- Melody control (F0 contour)
- Score control (MIDI notes)

**Models:** Need to download via `hf download`

**Launch:** `bash scripts/start_soulxsinger.sh`

**Download models:**

```bash
source /srv/containers/edq/venv_soulxsinger/bin/activate
pip install -U huggingface_hub

hf download Soul-AILab/SoulX-Singer --local-dir /srv/containers/edq/models/SoulX-Singer
hf download Soul-AILab/SoulX-Singer-Preprocess --local-dir /srv/containers/edq/models/SoulX-Singer-Preprocess
```

**Resources:**

- Paper: https://arxiv.org/abs/2602.07803
- Demo: https://soul-ailab.github.io/soulx-singer/
- GitHub: https://github.com/Soul-AILab/SoulX-Singer

**What it does:**

- Reasoning-based editing
- Text rendering in images

**Architecture:** 5B parameters (3B VLM + 2B DiT)

**Current status:**

- Core dependencies installed (PyTorch, transformers, diffusers, flash_attn)

- Placeholder UI shows setup instructions

**To complete setup:**

```bash

pip install xtuner mmengine

  --local-dir /srv/containers/edq/models/deepgen-1.0
```

**Launch:** `bash scripts/start_deepgen.sh` (shows setup info)

**Resources:**

- Paper: https://arxiv.org/abs/2602.12205
