🎯 RECOMMENDED: GGUF Quantized Version (Works on 16GB!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ WILL RUN on your RTX 5070 Ti (16GB VRAM)
✅ Good quality with Q4/Q5 quantization
✅ Fully local and private

Run this command:
    bash ~/setup-wan-gguf.sh

Choose option 3 (Q4_K_S) or 4 (Q5_K_S) when prompted.

Then start ComfyUI:
    cd ~/comfyui-wan/ComfyUI
    source ../venv/bin/activate
    python main.py

Open: http://localhost:8188


🌐 ALTERNATIVE: Cloud Service (Fastest)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
No installation, runs on powerful cloud GPUs

Run this command:
    python3 ~/launch-wan-cloud.py

🎬 WHAT THIS DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ANIMATION MODE:
  Video (person dancing) + Character image = Animated character

REPLACEMENT MODE:
  Video (with character) + New character = Replaced character


💡 TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✓ Start with Q4_K_S quantization (good quality, 10.6 GB)
✓ Use Q5_K_S if you want better quality (12.3 GB)
✓ Short videos work better (5-15 seconds)
✓ First run takes longer (model loading)
